# Python Data Processor

## Goal
Build a polished Python tool for common CSV/Excel automation: validate structure, clean and normalize data, handle missing values, remove duplicates, combine datasets, calculate summaries, and export clean results.

## Planned features
- CSV/XLSX input and export
- Validation, cleaning, missing-value handling and deduplication
- Merge/combine files and summary statistics
- Logging and clear error reporting
- Automated tests and example datasets
- Optional simple GUI/drag-and-drop interface

## Portfolio objective
Demonstrate Python, pandas, data processing, automation, testing, documentation, and reliable handling of real-world files.

## Status
Planning / initial development.
